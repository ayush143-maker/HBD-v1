# HBD-v1

A personalised birthday microsite for Anya, with animated typography and a sequence of visual sections that unfold like a greeting. The page is a self-contained web experience; keep referenced image paths intact when updating its assets.

## Preview locally

Open `index.html` in a modern browser. No package installation is required. For a local HTTP preview, run:

    python -m http.server 8000

Visit http://localhost:8000.

## Personalising the page

Update the greeting and media together, and check the page on both phone and desktop screens.
